# 键盘快捷键

| 快捷键 | 行为 |
|---|---|
| `/` | 聚焦搜索框 |
| `Esc` | 关闭弹窗 / 清空搜索 |
| `j` | 向下导航端口列表 |
| `k` | 向上导航端口列表 |
| `?` | 显示快捷键帮助 |
| `g` + `1-9` | 快速跳转前 9 个自定义区间 |

快捷键在任何页面生效（除了输入框聚集时）。按 `ESC` 可随时退出。

## 设计原则

- **极少内存**：单页面不渲染多于 100 个卡片（虚拟滚动）。
- **极少 CPU**：刷新间隔 ≥ 30s，默认 60s。
- **极少磁盘**：每次快照仅保存必要 JSON，自动轮转。
- **极少依赖**：仅 Docker SDK + psutil + FastAPI + Vue 3。
